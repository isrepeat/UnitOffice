# UnitOffice.AscodSite

Самостоятельный локальный сервер демонстрационного реестра. Описание приложения находится в `Projects/Components/Application/AscodSite.xml` и подключено из `Components.xml`. Проект Visual Studio и решение обновляются через ProjectTools.

Соберите `UnitOffice.AscodSite` в конфигурации `Debug | x64` и запустите `UnitOffice.AscodSite.exe` из каталога сборки. Сервер слушает `http://127.0.0.1:8091/`. Для реестра откройте `/page1`, для карточки используйте двойной щелчок по строке.

Тестовые записи редактируются в `Data/Documents.xml`. Сборка копирует этот файл в `Data` рядом с EXE. Сервер читает выходной файл при каждом запросе `GET /api/v1/documents`, поэтому изменения в выходной копии видны после обновления страницы. В XML хранятся реквизиты и имена вложений. Текст демонстрационных вложений формируется в браузере.

Общий заголовочный HTTP-слой находится в `Sources/Windows/HttpHosting`. Сервер сайта задаёт маршруты и своё хранилище, а HTTP-слой обслуживает слушатель и обмен с клиентом.
