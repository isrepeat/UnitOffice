# UnitOffice

Первый проект в репозитории, **PersonalEventsBuilder**, переносит существующий Excel-проект **PersonalEventBuilder** в настольное приложение для Windows.

Excel-прототип использует книгу с макросами, историю событий и шаблоны для подготовки документов Word. В рабочей копии ExcelPrototype он находится в `PROJECTS_EXCEL/workbook/PersonalEventBuilder/`.

## Текущее состояние

Репозиторий подготовлен к началу разработки. Следующий этап — описать рабочие сценарии Excel-прототипа и определить, какие из них войдут в первую настольную версию.
